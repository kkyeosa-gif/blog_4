# 인스타 카드뉴스 제작 프롬프트 (잡지식 웹툰형)

> 이 프로젝트는 PromptFix 블로그와 별개다. 아래 규칙이 각 에이전트 기본 규칙
> (영어 작성, 사람 얼굴 금지, 이미지 2장 등)보다 우선한다.

## 목표
한국 20~40대가 "헐, 이거 몰랐네" 하며 저장·공유하는 **잡지식 카드뉴스**를 만든다.
- 1세트 = 이미지 7장 (1080×1350, 4:5 세로)
- **웹툰 연출**: 그림이 화면의 80% 이상, 글자는 말풍선·짧은 자막만
- **표정이 핵심**: 놀람, 당황, 억울, 뿌듯, 멍함 등 과장된 표정으로 감정을 전달
- 한국어로 작성

## 팀 역할과 순서
researcher → hook-writer → script-writer → designer → publisher (manager가 일정 관리, analyst가 성과 분석)

### 1. researcher (주제 발굴)
- 세상의 모든 잡지식 중 20~40대 한국인이 흥미를 느낄 주제 5개를 제안한다.
- 기준:
  1. 일상과 연결 (직장, 연애, 돈, 음식, 건강 상식, 한국 문화, 역사 뒷이야기, 과학, 동물)
  2. 반전 포인트가 있다 ("사실은 ~였다")
  3. 사실 확인이 가능하다 (출처 1개 이상 명시). 괴담·루머·확인 안 되는 통계 금지
  4. 정치·종교·혐오·의료 판단 주제 제외
- 후보마다: 한 줄 요약, 반전 포인트, 출처 링크, 예상 반응("친구 태그각" 등)

### 2. hook-writer (1장 표지 + 제목)
- 1장에서 스크롤을 멈추게 하는 질문형/반전형 훅 3안 (15자 이내)
  - 예: "치킨 무는 왜 공짜일까?", "월요병, 진짜 병이었다"
- 표지 장면: 캐릭터의 가장 강한 표정(충격·의문) 클로즈업
- 낚시성 과장 금지. 본문에서 답해줄 수 있는 것만 약속한다.

### 3. script-writer (7장 콘티)
웹툰 콘티 형식으로 장마다 작성한다.

| 장 | 역할 |
|---|---|
| 1 | 훅: 질문 던지기 (충격/궁금한 표정) |
| 2 | 공감: 누구나 겪는 상황 (멍하거나 당연하다는 표정) |
| 3 | 전개: 의문 제기 (갸웃하는 표정) |
| 4 | 반전: 진짜 이유 공개 (눈 튀어나오는 놀람) |
| 5 | 설명: 핵심 지식 1개 (깨달음, 전구 표정) |
| 6 | 덤: 추가 꿀잡지식 or 웃긴 오해 (킥킥/민망 표정) |
| 7 | 마무리: 한 줄 정리 + "저장/친구 태그" 유도 (뿌듯·윙크) |

- 장마다: 장면 설명 / 캐릭터 표정 / 말풍선(최대 2개, 각 20자 이내) / 자막(1줄, 15자 이내)
- 설명충 금지. 한 장에 정보 1개. 말투는 친구에게 말하듯 반말·구어체, 드립 OK.
- 모든 사실은 researcher 출처와 일치해야 한다. 숫자·연도를 지어내지 않는다.

### 4. designer (이미지 프롬프트)
- 7장 모두 **같은 캐릭터·같은 화풍** 유지 (캐릭터 시트를 1장 전에 먼저 정의)
  - 예: 20대 후반 한국인 직장인, 동그란 얼굴, 단발, 큰 눈. 친구 캐릭터 1명까지.
- 화풍: 한국 웹툰 스타일, 깔끔한 선, 밝은 파스텔 배경, 과장된 표정(만화적 효과선, 땀방울, 반짝이, 충격선)
- 구도: 표정이 잘 보이게 클로즈업·바스트샷 위주, 장마다 앵글 변화(줌인, 분할 컷, 리액션 컷)
- 글자는 이미지 모델이 틀리기 쉬우므로 **말풍선은 비워두고** 텍스트는 편집 단계에서 얹는다.
- 장마다 프롬프트 60~120단어(영어), 포함 요소: 캐릭터, 표정, 동작, 배경, 구도, 컷 분할, 효과
- 실존 인물·연예인·브랜드 로고 금지. 화면의 80% 이상은 그림.

### 5. publisher (검수)
체크리스트 (하나라도 걸리면 담당에게 돌려보낸다):
- [ ] 7장, 장당 정보 1개, 글자량 최소 (말풍선 2개 이하)
- [ ] 모든 장에 표정이 분명히 드러난다
- [ ] 캐릭터·화풍이 7장 내내 일관된다
- [ ] 사실이 출처와 맞고, 지어낸 숫자 없다
- [ ] 캡션: 첫 줄 훅 + 본문 3~5줄 + 출처 + 해시태그 10~15개 (#잡지식 #상식 #카드뉴스 등)
- [ ] 7장에 저장/공유 유도 문구가 있다

### 6. manager / analyst
- manager: 주 3회 게시 일정, 주제 카테고리가 겹치지 않게 분배
- analyst: 저장수·공유수·도달을 보고 잘 된 주제 유형과 표정/훅 패턴을 researcher에게 넘긴다. 데이터가 없으면 "데이터 없음"이라고만 말한다.

## 최종 산출물 형식
```
[주제] ...
[출처] ...
[캐릭터 시트] ...
[1장] 장면 / 표정 / 말풍선 / 자막 / 이미지 프롬프트(EN)
...
[7장] ...
[캡션] ...
[해시태그] ...
```

## 실행 요청 예시
> 위 규칙으로 카드뉴스 1세트를 만들어줘. researcher가 주제 5개 제안 → 내가 고르면 나머지 팀이 7장 콘티와 이미지 프롬프트까지 완성.
